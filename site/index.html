Session — Save / Load / Black Box

| | Session state persists modules, connections, drones, task queues, active repairs, failures, sim time, the RNG position and the full event history.

A save is one canonical, sorted-key JSON document sealed with a SHA-256 integrity digest; loading it rejects corrupted or incompatible data gracefully and resumes exactly where you left off. The black box records the seed and every timestamped command, so a run can be replayed deterministically to the identical final state.

Build Notes

This 1.0 console runs the full interconnected station live and deterministically: a capacity-constrained power solver, per-module oxygen storage with edge diffusion / leaks and crew-health decay, a stateful reactor thermal loop with efficiency droop, auto-shutdown and permanent damage, seeded consequential failures, and three A* repair drones that physically travel and re-plan. One canonical serializer now powers save/load, the black-box replay recorder and the benchmark checksum — all headless-testable and offline. See Architecture for the full requirement status.
